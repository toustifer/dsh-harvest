# Harvest 工作流（DSH / Codex 共用原则）

围绕用户问题选择渠道并读取原文。空结果与渠道失败分别记录；无需为了平台数量强行增加不相关来源。

`harvest_verify` 仅返回词汇匹配候选。由宿主模型比对原文、检查否定/日期/条件、区分支持与反驳。搜索摘要和标题不是核验证据；转载不自动计作独立来源。

`harvest_audit` 返回来源元数据与缺失项，不做可信度打分。报告给出就近引用与影响结论的证据缺口。

外部 Tavily 研究为可选能力：提交后保留任务 ID，再查询状态。提交结果未知时不自动重复提交；停止查询不等于取消远端任务。

Codex 完整工作流见 `skills/harvest-research/SKILL.md`。
